# Etiqueta
Etiqueta de estado o tipo: texto de 12 px en mayúsculas sobre un fondo suave, radio de 2 px.

- `.etiqueta`: neutra (fondo `fondo`, texto `texto-2`).
- `.etiqueta.alterna`: propuesta alternativa a otra.
- `.etiqueta.aviso`: «Próximamente», «En preparación».
- `.etiqueta.fundamental`: derechos fundamentales, que no se someten a votación. Amarillo con texto marino.
- Siempre con palabra: el color nunca es el único portador del significado.
