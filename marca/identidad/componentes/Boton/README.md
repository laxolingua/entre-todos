# Boton
Botón de acción: rectángulo de esquinas casi rectas (`radio-sm`), rótulo en mayúsculas Barlow 700, altura mínima 46 px.

- `.boton.rojo`: la acción principal de la pantalla. Una sola por bloque.
- `.boton`: acciones secundarias, borde marino de 2 px sobre blanco; al pasar el ratón se rellena de `marino`.
- `.boton.claro`: sobre fondos marinos.
- `.enlace-flecha`: acción ligera dentro de tarjetas («VER PROPUESTA →»), rojo y subrayado.
- El rótulo dice exactamente lo que pasa: «Vota», «Descargar CSV», «Salir ahora». Nada de «Haz clic aquí».
- El consumidor aporta el texto, el destino (`href`) o el `type` del botón.
