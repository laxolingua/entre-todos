# AvisoProximo
Bloque marino con la esquina inferior derecha cortada, para funciones que todavía no están listas.

- Título «Próximamente» y una o dos frases que dicen qué vendrá y qué se puede hacer mientras tanto.
- Se usa en Constituyente, Reconstrucción y en el espacio reservado de «¿Cuál es el plan?» (`#modulo-plan`), que el equipo colaborador sustituirá por su módulo.
- Nunca se publica una función a medias: o funciona, o lleva este aviso.
