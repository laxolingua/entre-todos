# Titulares
Jerarquía de titulares: antetítulo (kicker) rojo con raya, titular condensado en mayúsculas marino, barra corta debajo.

- h1 y h2: estilos `titular-1` y `titular-2`, Barlow Condensed 800, MAYÚSCULAS, color `marino`.
- El antetítulo (`.kicker`) va encima: 13 px, espaciado .14em, rojo con raya de 34×4 px. Sobre marino, `.kicker.claro` (texto blanco, raya amarilla).
- Barra bajo el h2 de sección: 64×6 px, `amarillo` o `rojo`. Nunca las dos.
- Un titular puede llevar una palabra en `rojo` para el énfasis. Una sola.
- Títulos de propuesta en tarjetas: mayúsculas y minúsculas tal como vienen del documento de origen.
